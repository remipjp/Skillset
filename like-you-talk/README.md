# like-you-talk

Most writing gets worse the moment we sit down to write it. We reach for fancy words, ~~stiffen up~~ tense up, and bury good ideas under prose nobody would ever say out loud.

This skill teaches Claude to do the opposite. It turns two Paul Graham essays, [Write Like You Talk](https://paulgraham.com/talk.html) (2015) and [Write Simply](https://paulgraham.com/simply.html) (2021), into five rules Claude actually follows:

- Write like you talk
- Use ordinary words
- Cut everything unnecessary
- Reduce friction to zero
- Never be complex by accident

The result is writing that sounds like a smart friend explaining an idea, not an essay trying to impress you. Ideas stay front and center. The words get out of the way.

Point it at a draft to clean it up, or ask it to write from scratch. Either way, the test is the same one PG uses: would you actually say this out loud?
